# Fabrícia Pinheiro · Site

Site de consultoria em Gestão de Pessoas (@fabipinheiro_rh).

- `index.html` · início, sobre, serviços (pessoas e empresas) e contato
- `materiais.html` · vitrine de materiais e cursos
- `pdi.html` · página de vendas do PDI que sai do papel
- `curriculo.html` · serviço de Currículo Estratégico
- `recrutamento.html` · serviço de Recrutamento & Seleção (formatos, valores e PDA opcional)
- `style.css` / `script.js` · estilo e interações compartilhados, incluindo a barra lateral de navegação (lista de páginas em `SITE_MAP`, no `script.js`)

Publicado via GitHub Pages (branch `main`, pasta raiz).
